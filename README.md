# Week 6 Java Solutions (Category C OOP, Encapsulation, Constructor Chaining & Static Members)

This repository contains clean, modular Java implementations for Week 6 problems, organized by dedicated Git branches:

- **`assignment` branch**: Contains 5 Assignment problems (Student Placements, Hostel Mess Wallet, Course Credits, Library ID Card, Student & College Info) and documentation.
